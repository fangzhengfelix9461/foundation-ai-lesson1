# Foundation of AI 第一堂课

方正 Felix 的中文阅读讲义，支持左右翻页、触屏滑动、目录搜索、连续阅读、字号调整和原图放大。

内容范围为用户提供的 PDF 第 1–13 页和第 14 页“待定：第二课”之前的部分。

- 419 行非空原文全部保留，按语义段落重新分页。
- 24 张图片以原始像素无损保存。
- 低分辨率公式同时提供清晰文字排版和原图。
- 原 PDF 页面的对照图仅包含第一堂课范围。
- 主讲人简介和课后资源单独成页。

静态网站，无构建依赖。入口为 `index.html`。

`source-content.json` 保留原文行与图片的来源位置；`coverage.json` 记录覆盖校验。
`extract.py` 和 `build.py` 为本地整理脚本，不包含登录信息或凭据。

原文的明显笔误以独立“阅读提示”补充，原文不删除。
