切分粒度与词性

不过，Token 不一定等于我们平时说的一个词。不同切分工具可能采用不同规则：

1代码块一 种拆法：小猫 / 喜欢 / 吃 / 鱼 → 4个 Token

2 另一种拆法：小 / 猫 / 喜 / 欢 / 吃 / 鱼 → 6个 Token

这是按比较完整的词来拆，每一块通常有比较清楚的意思。

这是按单个汉字来拆，块更小。例如“喜”和“欢”被分开了。

这里区别的是切分粒度，不是词性。

如果我们给“小猫”标上“名词”、给“喜欢”标上“动词”，那叫词性标注，是另一件事：

因此，同一句话有多少 Token，要看具体使用哪一种切分工具。

大语言模型的 tokenizer 通常不需要先判断“这是名词还是动词”，再决定怎么切。它按照自己的词表和切分规则处理文字。

一个 token 在这里对应的是一组含三个数的向量，而不是“很多组数字”。

只有编号，为什么还不够？

先说明：编号告诉我们“是谁”，但编号大小不代表含义。

“现在，我们已经给‘猫’和‘狗’各分配了一个编号。计算机可以区分：这是猫，那个是狗。”

“但编号就像学号。两个同学的学号挨在一起，不代表他们性格相似；学号相差很远，也不代表他们没有共同点。”

“同样，猫和狗的编号相差多少，并不能告诉我们：它们都是动物，都可能被人当作宠物养。”

编号适合查找身份，不能直接用编号的大小和差值表达词语之间的关系。

学号与身高、体重

向量和普通的编号有什么区别

第一步：先用大家熟悉的例子，区分“编号”和“描述”。

“假设一个学生的学号是28。只看28，我们能知道他多高、多重吗？”

“不能。换成29号，他也不会因此长高一厘米。学号只是用来找到这个人。”

“但如果我告诉你，这个学生身高175厘米、体重65公斤，那这两个数字就有不同的作用了：它们在描述这个人。”

“把身高和体重按照固定顺序放在一起，写成 [175, 65] ，这就是一个最简单的向量。”

重点不是数字变多了，而是数字的用途变了。

顺序可以改，但必须一起改

顺序是我们事先约定的。比如也可以改成：

代码块

1 新顺序：[加油次数, 喂食次数, 宠物次数]2

3 猫： [0, 2, 1]

4 狗： [0, 1, 1]

5 汽车： [2, 0, 0]

信息没有变，只是所有行一起调整了列的顺序。

不能只改猫的顺序，却不改狗和汽车的顺序，否则同一个位置代表的事情就不一样了。

横着写是为了方便展示；数学中也可以竖着写。关键是明确每个位置对应什么，并在后续运算中保持一致。
